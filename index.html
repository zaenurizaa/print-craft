10 Usability Heuristics Jakob Nielsen

Standarisasi Desain Interaksi Sistem PrintCraft Duta Media

1. Visibility of System Status

Status pesanan disajikan melalui badge pill standar (Lunas, DP 50%, Overdue, Near Deadline) dan stepper progres produksi 5 tahap.

2. Match Between System and Real World

Mengadopsi kosakata industri konveksi: DP, Piutang, Cotton Combed, Plastisol HD, Work Order Print (WOP), dan PO Bahan Kaos.

3. User Control and Freedom

Setiap formulir, modal, dan slide-over memiliki tombol Batal dan tombol kembali untuk membatalkan proses kapan saja.

4. Consistency and Standards

Penerapan konsisten typography Manrope/Inter/JetBrains Mono dan komponen layout Softro SaaS di seluruh 30 layar.

5. Error Prevention

Konfirmasi modal peringatan sebelum aksi hapus data master/akun/cabang dan validasi batas minimum kuantiti order (12 pcs).

6. Recognition Rather Than Recall

Kalkulator otomatis menghitung HPP, margin, dan diskon live tanpa perlu menghafal rumus manual.

7. Flexibility and Efficiency of Use

Pencarian instan dengan shortcut keyboard (⌘K), filter cabang/status cepat, dan integrasi WhatsApp satu-klik.

8. Aesthetic and Minimalist Design

Grid desktop 1440px terstruktur, visual hierarchy bersih tanpa ornamen dekoratif yang tidak fungsional.

9. Help Users Recognize, Diagnose, and Recover from Errors

Pesan notifikasi dan empty state terarah memberikan panduan langkah perbaikan yang jelas.

10. Help and Documentation

Dokumentasi audit heuristik terintegrasi pada setiap layar antarmuka pengguna.
